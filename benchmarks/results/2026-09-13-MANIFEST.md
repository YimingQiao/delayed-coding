The index32 experiment is retained in [index32.patch](../experiments/index32.patch).
Apply it to a separate checkout at `19199fe`. To reproduce index28 instead, remove
the added `#[repr(C, align(16))]` attribute from `Bucket`; all other changes match.
Neither intermediate layout is the current default. Flat slots are opt-in after
the native model-switching regression; they retain 28 bytes
of compact decode-table storage per bucket, in two allocations; model header and
allocator bookkeeping are outside `Model::table_bytes`.
The native executable is built with `cargo bench --bench throughput --no-run`;
both revisions use the same Rust compiler and flags. It reports its own model
memory/build-time columns and a different generator, not rANS comparisons.

The first SIMD synthetic run overlapped a brief (~18 ms) diagnostic `perf stat`
invocation on CPU 2. Treat its fine differences as exploratory; the later file
and alias-repeat runs did not overlap that diagnostic. Some short skewed-model
rows vary materially between runs, even without core changes. Keep those results;
do not report the lowest observation as representative performance. Assembly
inspection confirms conditional alias selection became boolean-index addressing;
we have not yet attributed the end-to-end speedup with isolated hardware counters.
